❤️ HRIDYAM AI

Because every heart matters.

HRIDYAM AI is an AI-powered cardiovascular risk prediction and visualization platform designed to make complex heart health information easier to understand.

By combining Machine Learning, Explainable AI, and interactive 3D heart visualization, the project aims to transform clinical data into meaningful and visually understandable insights.

🚀 Key Features

- CAD Risk Prediction: Estimates the risk of Coronary Artery Disease.
- Vessel-Specific Prediction: Predicts stenosis probabilities for LAD, LCX, and RCA.
- Interactive 3D Heart: Explores coronary artery regions through 3D visualization.
- Explainable AI: Uses SHAP-based insights to understand feature contributions.
- Clinical Dashboard: Displays prediction results, clinical parameters, and visual insights.
- Machine Learning Evaluation: Evaluates models using Accuracy, Precision, Recall, F1-score, and ROC-AUC.

🧠 Technology Stack

- Programming Language: Python, JavaScript
- Machine Learning: Scikit-learn
- Data Processing: Pandas, NumPy
- Backend: FastAPI
- Frontend: React, Vite
- 3D Visualization: Three.js, React Three Fiber
- Explainable AI: SHAP
- Dataset: UCI Extension of the Z-Alizadeh Sani Dataset

🎯 Project Objective

The primary objective of HRIDYAM AI is to make cardiovascular risk information more accessible and understandable by combining AI-driven predictions with interactive visual representations.

🔮 Future Scope

- Improved prediction models.
- Enhanced 3D anatomical visualization.
- More detailed explainable AI insights.
- Improved user experience and dashboard functionality.
- Further evaluation using appropriate clinical datasets.

⚠️ Disclaimer

HRIDYAM AI is a research and educational prototype. Its predictions are intended for demonstration and decision-support exploration only. It is not a substitute for professional medical advice, diagnosis, or clinical imaging.
